简化版的夜间模式。

`模式` 可选 `跟随 B 站` / `跟随系统` / `计划时段`，计划时段的结束时间小于起始时间时视为次日，如 `18:00` 至 `6:00` 表示晚上 18:00 到次日 6:00。

`跟随 B 站` 模式仅将脚本的界面主题和 B 站官方主题同步，不会主动切换 B 站主题。如需在自定义顶栏中切换 B 站官方主题，可以安装 `自定义顶栏 - 深色模式开关` 插件。

### 已知限制

- 直播页的脚本样式始终跟随 B 站，「跟随系统」和「计划时段」不生效。

> 注：在某些浏览器 (如 `Microsoft Edge`) 中，跟随系统仅会同步浏览器的亮 / 暗主题。
