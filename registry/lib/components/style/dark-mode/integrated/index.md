简化版的夜间模式，默认跟随 b 站官方的深色/浅色主题，也可选择跟随系统或按计划时段自动切换 b 站和脚本的界面主题。

`模式` 可选 `跟随 b 站` / `跟随系统` / `计划时段`，计划时段的结束时间小于起始时间时视为次日，如 `18:00` 至 `6:00` 表示晚上 18:00 到次日 6:00。

`跟随 b 站` 模式仅将脚本的界面主题和 b 站官方主题同步，不会主动切换 b 站主题。如需在自定义顶栏中手动切换 b 站官方主题，可以安装 `自定义顶栏 - 深色模式开关` 插件。

> 注：在某些浏览器 (如 `Microsoft Edge`) 中，跟随系统仅会同步浏览器的亮 / 暗主题。
