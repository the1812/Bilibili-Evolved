使用重新设计的仪表盘首页替换原本的首页。

## 使用限制

「仪表盘首页」与「极简首页」「清爽首页」「仅搜索首页」互斥，同一时间只能启用其中一个。

## 选项

- 可单独显示或隐藏每个标签页。
- 「显示『稍后再看』」同时控制标签页和视频封面上的「稍后再看」按钮。
- 在「卡片布局」中选择横向、紧凑或纵向布局。
- 「卡片行列数」在横向和紧凑布局中表示列数，在纵向布局中表示行数。设为 `0` 时自动计算。
- 启用「在网址中记住当前标签页」后，刷新页面会恢复当前标签页。
- 可为动态、专栏、视频及其他链接分别开启首页内预览。
