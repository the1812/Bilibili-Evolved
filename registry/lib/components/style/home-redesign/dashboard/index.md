使用重新设计的仪表盘首页替换原本的首页。

请注意:

- 此功能与 `极简首页` / `清爽首页` / `仅搜索首页` 互斥, 请勿同时开启

选项说明:

- 显示标签页: 显示或隐藏每个标签页
- 显示「稍后再看」: 同时控制视频封面上的「稍后再看」按钮
- 卡片布局：选择横向、紧凑或纵向布局
- 卡片行列数：使用横向、紧凑布局时设置列数，使用纵向布局时设置行数，`0` 为自动
- 在网址中记住当前标签页：在网址中添加参数，刷新后仍会打开该标签页
- 在首页内打开链接：使用嵌入窗口打开链接
