使用重新设计的仪表盘首页替换原本的首页, 初始布局基于 `极简首页`.

`视频` 标签页按发布日期分组, 并在卡片左侧标注日期.
`动态` 标签页以瀑布流展示关注动态, 支持图文、转发、视频及专栏等内容, 需要登录 B 站.
`关注` 标签页以瀑布流展示已关注账号的头像、签名和关注日期, 滚动时自动加载, 需要登录 B 站.

请注意:
- 此功能与 `极简首页` / `清爽首页` / `仅搜索首页` 互斥, 请勿同时使用.
- 此功能会禁用首页的[悬浮视频](https://github.com/the1812/Bilibili-Evolved/discussions/4404), 变为直接跳转到视频页面.

选项说明:
- 显示标签页: 可分别开启或关闭 `视频`、`动态`、`关注`、`热门` 和 `推荐`。`推荐`在登录后使用个性化推荐。
- 默认标签页: 若所选标签页已关闭, 则打开第一个显示的标签页
- 自定义列数: 为 `0` 时根据视图宽度推断, 大于 `0` 的值将作为固定的列数
