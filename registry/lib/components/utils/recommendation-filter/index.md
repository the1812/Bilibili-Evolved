过滤原生首页和视频右侧的推荐内容。启用后，通过左侧“功能 → 推荐过滤设置”管理规则。

- **通用过滤**：命中任一关键词即过滤；**组合组**：同时命中组内所有关键词才过滤。忽略英文大小写，统一全角半角，不支持正则。
- **其他规则**：最低时长、精确播放量和发布时间。已关注豁免优先执行；关注豁免、发布时间仅首页生效。
- 首页卡片“⋮ → 导入过滤词”可将标题中的词加入通用过滤；“临时显示已过滤内容与原因”用于检查命中结果。

设置自动保存并立即生效。窗口可拖动、调整大小，点击外部保持打开。

只读取页面已加载的数据，不额外查询视频或用户资料；缺失字段跳过对应规则。不处理搜索、热门、动态或第三方首页。
