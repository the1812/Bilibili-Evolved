在视频页复制链接时, 把剪贴板里的内容替换成按模板拼好的分享文案, 自动带上 UP 主、时长、播放量等信息.

- 在任意页面复制到视频链接时生效, 其他复制不受影响; 视频信息按 BV 号获取.
- 内置预设: 标准、极简、数据、Markdown、纯链接、JSON, 也可以自定义模板.
- 选择预设时显示该预设的模板预览, 选择「自定义」后预览会变成可编辑的输入框.
- 选项修改只写进面板里的草稿, 需要点击「保存配置」才会真正保存; 有未保存修改时会提示, 保存成功后显示「已保存」.
- 短链直接拼接为 `https://b23.tv/{bv}`, 不需要额外请求.
- 视频信息按 BV 号缓存 10 分钟, 只在复制时按需请求, 失败时保持原样放行.
- 模板里写 `{cover_image}` 时, 封面图会和文案一起写进剪贴板; 去掉它只复制文字.

## 封面图

- 剪贴板里的图片只接受 `image/png`, 所以封面会先经 canvas 缩放到「封面图最大宽度」, 结果按链接和宽度缓存 30 分钟.
- `{cover_image}` 就是封面图的唯一开关和位置: 写在模板哪一行, 图片就插在哪一行; 去掉就完全不附带图片.
- 带封面时写入 `text/plain` + `text/html`, HTML 使用 QQ 能识别的结构(`span.text-element` + `img[data-role=pic]`), 图片是 `https://...@720w.jpg` 这样的 CDN 缩放链接, 不内嵌 base64. 这是实测能让 QQ/微信都粘出图文的关键: 内嵌 data URI 会被 QQ 整次拒绝.
- 图片由聊天软件在粘贴时联网下载, 断网粘贴只剩文字.
- 剪贴板里永远有可用的文字, 不会出现只有图片、粘不进文本框的情况.
- 只在复制的内容属于当前页面这个视频时附带封面, 复制别处的视频链接不受影响.
- 浏览器快捷键 `Ctrl+C` 走的是 `copy` 事件, 这条路径只能写文字, 不会附带封面; 写入图片失败(例如浏览器不支持或缺少用户手势)时会自动回退为纯文本.

## 可用变量

| 变量 | 说明 |
| --- | --- |
| `{title}` | 视频标题 |
| `{up}` / `{uid}` / `{up_url}` | UP 主昵称 / UID / 空间链接 |
| `{bv}` / `{av}` / `{aid}` | BV 号 / av 号 / 数字 aid |
| `{url}` / `{short_url}` | 去参数的长链接 / `b23.tv` 短链 |
| `{date}` | 发布时间, 格式由选项决定 |
| `{duration}` | 当前分 P 时长 |
| `{views}` `{danmaku}` `{likes}` `{coins}` `{favorites}` `{replies}` `{shares}` | 各项数据 |
| `{tname}` | 分区名 |
| `{part}` / `{p}` / `{page_count}` | 分 P 标题 / 当前分 P / 总分 P 数 |
| `{desc}` | 简介, 可配置截断长度 |
| `{cover}` | 封面图链接 |
| `{cover_image}` | 封面图本身, 写到模板哪一行就插在哪一行 |

`{cover_image}` 同时是封面图的开关: 模板里没有它就不会附带图片. 纯文本输出里它会被去掉.

模板里不认识的 `{变量}` 会在编辑器中提示; 复制时会保留原始内容, 不会输出带错误占位符的文案.
