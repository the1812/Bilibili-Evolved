在视频页点击分享按钮时，复制按模板生成的分享文案（含标题、UP 主、链接等信息）；悬停弹出的原生分享面板仍可正常使用。

- 内置预设：标准、极简、数据、Markdown、纯链接、JSON，也可以自定义模板。
- 在设置面板中修改后，点击「保存配置」生效。
- 模板中写 `{cover_image}` 时，封面图会和文案一起复制，可粘贴到 QQ / 微信等支持图文的应用。
- 多 P 视频的链接会定位到当前分 P。

## 可用变量

| 变量 | 说明 |
| --- | --- |
| `{title}` | 视频标题 |
| `{up}` / `{uid}` / `{up_url}` | UP 主昵称 / UID / 空间链接 |
| `{bv}` / `{av}` / `{aid}` | BV 号 / av 号 / 数字 aid |
| `{url}` / `{short_url}` | 去参数的长链接 / 短链接（多 P 视频为带分 P 的长链接） |
| `{date}` | 发布时间，格式由选项决定 |
| `{duration}` | 当前分 P 时长 |
| `{views}` `{danmaku}` `{likes}` `{coins}` `{favorites}` `{replies}` `{shares}` | 各项数据 |
| `{tname}` | 分区名 |
| `{part}` / `{p}` / `{page_count}` | 分 P 标题 / 当前分 P / 总分 P 数 |
| `{desc}` | 简介，可配置截断长度 |
| `{cover}` | 封面图链接 |
| `{cover_image}` | 封面图，写在模板哪一行就插入到哪一行 |

JSON 模板中的值请使用 `{title|json}` 这类 `|json` 修饰符，以正确转义引号、反斜杠和换行。

模板含未知变量时会提示，并只复制视频链接。
